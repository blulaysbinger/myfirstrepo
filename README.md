## 🚀 How to Run Locally

Because this project is built using vanilla technologies with zero build steps or heavy dependencies, you can run it immediately in any browser:

### Option 1: Direct File Launch
Double-click `index.html` or right-click and choose **Open with Browser** (Chrome, Edge, Firefox, Safari).

### Option 2: Using a Local HTTP Server (Recommended)
Using Python (built into most machines):
```bash
python -m http.server 8000
```
Then navigate to:
```
http://localhost:8000
```

Using Node.js:
```bash
npx serve .
```
